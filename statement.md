# Project Statement

## Problem Statement

Maintaining student attendance manually can make it difficult to keep track of presents, absences, and attendance percentages. This project provides a simple Python program to manage student attendance records.

## Scope of the Project

The project is used to add student details, mark attendance, view attendance records, and search for a student using their roll number.

## Target Users

The system can be used by teachers or staff to maintain basic student attendance records.

## High-Level Features

- Add a student using roll number and name.
- Mark a student as Present or Absent.
- View attendance records.
- Search for a student using roll number.
- Calculate and display attendance percentage.
- Store attendance records in a text file.
